# Landing Page DNA Autocenter

Este é o repositório da **Landing Page DNA Autocenter**, um projeto desenvolvido para apresentar os serviços, diferenciais e informações da oficina mecânica DNA Autocenter. O objetivo é oferecer uma experiência moderna e informativa para clientes e visitantes, facilitando o contato e divulgação dos serviços.

## 🚗 Sobre o projeto

O layout destaca os principais serviços, a história da empresa e a estrutura da oficina, e facilita o contato via WhatsApp e outros canais.

## Tecnologias utilizadas

- **HTML5** semântico, com dados estruturados (schema.org)
- **CSS3** moderno (Grid, `clamp()`, animações ligadas à rolagem como melhoria progressiva)
- Sem JavaScript, sem dependências e sem etapa de build
- Fonte Archivo hospedada no próprio projeto e imagens em WebP responsivas

## 🚀 Como rodar o projeto localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/Pedrodev17/landing-page-DNA-Autocenter-.git
   ```
2. Abra o arquivo `index.html` no navegador.

## 🗂️ Estrutura

- `index.html`: conteúdo da página
- `style.css`: estilos
- `fontes/`: fonte variável Archivo
- `imagens/`: fotos originais
- `imagens/otimizadas/`: versões usadas na página (WebP, com placas de clientes desfocadas)

## 🛠️ Funcionalidades

- Apresentação dos serviços da DNA Autocenter
- Integração com WhatsApp e Instagram
- Link do endereço para o Google Maps
- Layout responsivo, adaptado para smartphones e desktops
